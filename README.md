# Трекер прочитаних книжок
Автор: Терновий Валентин

## Про проєкт
Продукт дозволяє відстежувати прочитані книги, темп читання та жанри. Цільова аудиторія це люди, яка хочуть систематизувати свій читацький досвід і вести статистику всього, що читають. Дані отримуються через публічне Open Library API.

## Запуск
1. Створити віртуальне середовище: python -m venv .venv
2. Активувати його.
3. Встановити залежності: pip install -e ".[dev]"
4. Запустити: booktracker

Нормалізація працює.
